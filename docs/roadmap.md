# Roadmap

## Fundação local (esta etapa)

API básica de criação/listagem/consulta, análise conservadora por regras, validação, testes com mensagens sintéticas, frontend sem dados demonstrativos e documentação Windows.

## Etapas futuras sujeitas a aprovação

1. Revisão humana: edição, aprovação, rejeição, autorização e trilha de auditoria completa.
2. Persistência durável, controle de acesso, retenção e recuperação.
3. Avaliação de modelo de IA com dados sintéticos, política institucional e escolha de fornecedor.
4. Integrações institucionais opcionais após confirmação de disponibilidade e permissões.

Nenhuma dessas etapas futuras está ativada nesta base. Não existe envio de e-mail.

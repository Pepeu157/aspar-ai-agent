# Integrações externas — não implementadas

Nesta etapa não há acesso ao Microsoft 365, Outlook/Exchange, Microsoft Graph, envio de e-mail, Power Automate, SharePoint, Dataverse nem provedor externo de IA. A eventual integração exigirá confirmação institucional, autorização formal, permissões mínimas e revisão de segurança. Não configurar credenciais reais neste repositório.
